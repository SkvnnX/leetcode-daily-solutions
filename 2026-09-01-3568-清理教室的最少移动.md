- 难度：Medium（中等）

## 题意概括

给定一个 `m x n` 的教室网格和最大能量 `energy`。`S` 是起点，`L` 是必须收集的垃圾，`R` 是能量重置点，`X` 是障碍，`.` 是空地。每走一步消耗 1 点能量；到达 `R` 后恢复满能量。求收集所有垃圾的最少移动次数，无法完成返回 `-1`。

## 关键思路

这是带状态的网格最短路。只记录位置不够，因为同一格子在“已收集垃圾集合”或“剩余能量”不同时，后续可达性不同。

使用 BFS，状态为 `(row, col, mask, remain)`：位置、已收集垃圾集合、剩余能量。`mask` 用二进制压缩垃圾集合。每次移动代价都是 1，所以 BFS 第一次取出 `mask == fullMask` 的状态时就是最短答案。

转移时，若 `remain == 0` 则不能继续移动；否则枚举四个方向，跳过越界和障碍。进入新格子后能量减 1；若进入 `R`，立刻恢复为 `energy`；若进入 `L`，更新 `mask`。

## 复杂度分析

设网格大小为 `m x n`，垃圾数量为 `k`，最大能量为 `E`。

- 时间复杂度：`O(m * n * 2^k * E)`
- 空间复杂度：`O(m * n * 2^k * E)`

## 容易踩坑点

1. 访问标记必须包含 `(位置, mask, remain)`，否则会错误剪枝。
2. 到达 `R` 后要立即恢复满能量，包括刚好用最后 1 点能量走到 `R`。
3. 收集后的 `L` 仍可再次经过，不能视为障碍。
4. `remain == 0` 时不能继续扩展；本解法中 `R` 在入队前已恢复。
5. BFS 第一次取出 `mask == fullMask` 的状态就是最短答案。

## LeetCode 可提交解法：C++

```cpp
class Solution {
public:
    int minMoves(vector<string>& classroom, int energy) {
        int m = classroom.size(), n = classroom[0].size();
        vector<vector<int>> litterId(m, vector<int>(n, -1));
        int sr = -1, sc = -1, k = 0;
        for (int i = 0; i < m; ++i) for (int j = 0; j < n; ++j) {
            if (classroom[i][j] == 'S') sr = i, sc = j;
            else if (classroom[i][j] == 'L') litterId[i][j] = k++;
        }
        int fullMask = (1 << k) - 1;
        if (fullMask == 0) return 0;
        vector<vector<vector<vector<char>>>> seen(m, vector<vector<vector<char>>>(n, vector<vector<char>>(1 << k, vector<char>(energy + 1))));
        queue<array<int, 5>> q;
        seen[sr][sc][0][energy] = 1;
        q.push({sr, sc, 0, energy, 0});
        int dirs[5] = {1, 0, -1, 0, 1};
        while (!q.empty()) {
            auto [r, c, mask, remain, dist] = q.front(); q.pop();
            if (mask == fullMask) return dist;
            if (remain == 0) continue;
            for (int d = 0; d < 4; ++d) {
                int nr = r + dirs[d], nc = c + dirs[d + 1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n || classroom[nr][nc] == 'X') continue;
                int nextRemain = remain - 1;
                if (classroom[nr][nc] == 'R') nextRemain = energy;
                int nextMask = mask;
                if (litterId[nr][nc] != -1) nextMask |= 1 << litterId[nr][nc];
                if (!seen[nr][nc][nextMask][nextRemain]) {
                    seen[nr][nc][nextMask][nextRemain] = 1;
                    q.push({nr, nc, nextMask, nextRemain, dist + 1});
                }
            }
        }
        return -1;
    }
};
```

## LeetCode 可提交解法：Python 3

```python
from collections import deque
from typing import List

class Solution:
    def minMoves(self, classroom: List[str], energy: int) -> int:
        m, n = len(classroom), len(classroom[0])
        litter_id = {}
        sr = sc = -1
        for i in range(m):
            for j in range(n):
                if classroom[i][j] == 'S': sr, sc = i, j
                elif classroom[i][j] == 'L': litter_id[(i, j)] = len(litter_id)
        full_mask = (1 << len(litter_id)) - 1
        if full_mask == 0: return 0
        q = deque([(sr, sc, 0, energy, 0)])
        seen = {(sr, sc, 0, energy)}
        dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]
        while q:
            r, c, mask, remain, dist = q.popleft()
            if mask == full_mask: return dist
            if remain == 0: continue
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if not (0 <= nr < m and 0 <= nc < n) or classroom[nr][nc] == 'X': continue
                next_remain = remain - 1
                if classroom[nr][nc] == 'R': next_remain = energy
                next_mask = mask
                if (nr, nc) in litter_id: next_mask |= 1 << litter_id[(nr, nc)]
                state = (nr, nc, next_mask, next_remain)
                if state not in seen:
                    seen.add(state)
                    q.append((nr, nc, next_mask, next_remain, dist + 1))
        return -1
```
