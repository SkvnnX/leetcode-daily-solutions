# 2026-09-15｜LeetCode 410. 分割数组的最大值

> **题目来源标记：华为面试原题（爱心蔬菜配送）**

## 原题对应关系

这道“爱心蔬菜配送”题对应：

- **LeetCode 410. 分割数组的最大值**
- 英文题名：**Split Array Largest Sum**
- 难度：困难
- 题目链接：https://leetcode.cn/problems/split-array-largest-sum/

两道题的变量和含义可以一一对应：

| 爱心蔬菜配送 | LeetCode 410 |
|---|---|
| `communities[i]`：第 `i` 个社区的家庭数 | `nums[i]`：数组中的非负整数 |
| `num` 个志愿者 | 把数组分成 `k` 个非空子数组 |
| 每名志愿者负责编号连续的一段社区 | 每个子数组必须连续 |
| 志愿者并行配送 | 总完成时间由工作量最大的志愿者决定 |
| 每户配送耗时 1 小时 | 每段社区的家庭总数就是该志愿者耗时 |
| 最短完成时间 | 最小化所有连续分段中的最大元素和 |

因此，目标就是把 `communities` 分成 `num` 个非空连续区间，使区间和的最大值尽可能小。

> 以下解法默认 `communities[i] >= 0` 且 `1 <= num <= communities.size()`，与 LeetCode 410 的约束一致。如果志愿者多于社区，可让多余志愿者不分配任务，此时答案为最大社区家庭数。

## 题意概括

给定非负整数数组 `communities` 和志愿者数量 `num`。每个社区只能由一名志愿者配送，每名被分配任务的志愿者负责一段编号连续且非空的社区。

一个志愿者的配送时间等于其负责社区的家庭总数。所有志愿者可以并行工作，所以全部任务的完成时间等于所有志愿者配送时间的最大值。

求合理分配后最短的总完成时间。

## 关键思路：二分答案 + 贪心校验

直接枚举所有分割方法代价很高，但答案具有单调性：

- 如果限制每名志愿者最多配送 `limit` 户，并且可以完成分配；
- 那么把限制放宽为任何大于 `limit` 的数，也一定可以完成。

因此可以二分“最大配送时间”的最小可行值。

### 1. 确定二分范围

- 下界：`max(communities)`。一个社区不能拆给多个志愿者，家庭数最多的社区必须由某一人独立承担。
- 上界：`sum(communities)`。让一名志愿者负责所有社区一定可以完成。

### 2. 判断给定时间是否可行

从左到右贪心地给当前志愿者安排尽可能多的连续社区：

1. 如果加入下一个社区后总家庭数不超过 `limit`，继续加入当前分段。
2. 如果超过 `limit`，必须从该社区开始启用下一名志愿者。
3. 最后统计最少需要多少名志愿者。

如果需要的志愿者数不超过 `num`，说明 `limit` 可行；否则不可行。

### 3. 为什么贪心校验正确

在最大工作量不能超过 `limit` 的前提下，当前志愿者尽量多负责社区，能够让剩余社区最少，因此得到的是完成任务所需的最少志愿者数量。

如果这种最节省人数的分法仍需要超过 `num` 人，其他分法更不可能可行；反之，如果使用人数不超过 `num`，由于数组元素非负且 `num <= n`，可以继续拆分某些非空区间直到恰好使用 `num` 人，并且不会增大最大区间和。

## 复杂度分析

设社区数量为 `n`，所有家庭总数为 `S`：

- 每次可行性检查需要 `O(n)` 时间。
- 二分执行 `O(log S)` 次。
- 总时间复杂度：`O(n log S)`。
- 空间复杂度：`O(1)`。

## 容易踩坑点

- 每名志愿者负责的社区编号必须连续，不能把不相邻社区分给同一个人。
- 每个社区不能拆分，因此答案下界不是平均值，而是 `max(communities)`。
- 志愿者并行工作，答案是各分段家庭数的最大值，不是所有家庭数之和。
- 可行性判断比较的是“所需人数是否 `<= num`”，不是必须在贪心过程中恰好等于 `num`。
- C++ 中建议使用 `long long` 保存数组总和及二分中点，避免求和溢出。

## LeetCode 可提交解法：C++

```cpp
class Solution {
public:
    int splitArray(vector<int>& nums, int k) {
        long long left = *max_element(nums.begin(), nums.end());
        long long right = accumulate(nums.begin(), nums.end(), 0LL);

        auto canSplit = [&](long long limit) {
            int groups = 1;
            long long currentSum = 0;

            for (int value : nums) {
                if (currentSum + value > limit) {
                    ++groups;
                    currentSum = value;
                } else {
                    currentSum += value;
                }
            }
            return groups <= k;
        };

        while (left < right) {
            long long middle = left + (right - left) / 2;
            if (canSplit(middle)) {
                right = middle;
            } else {
                left = middle + 1;
            }
        }
        return static_cast<int>(left);
    }
};
```

## LeetCode 可提交解法：Python 3

```python
class Solution:
    def splitArray(self, nums: list[int], k: int) -> int:
        left, right = max(nums), sum(nums)

        def can_split(limit: int) -> bool:
            groups = 1
            current_sum = 0

            for value in nums:
                if current_sum + value > limit:
                    groups += 1
                    current_sum = value
                else:
                    current_sum += value
            return groups <= k

        while left < right:
            middle = (left + right) // 2
            if can_split(middle):
                right = middle
            else:
                left = middle + 1
        return left
```

## ACM 答题模式

### 输入格式

第一行输入两个整数 `n` 和 `num`，分别表示社区数量和志愿者数量。

第二行输入 `n` 个非负整数，表示每个社区的家庭数。

```text
n num
communities[0] communities[1] ... communities[n-1]
```

### 输出格式

输出完成全部配送任务所需的最短小时数。
